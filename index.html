Prices refresh automatically every 30 seconds (with automatic retry/backoff on failure, and the last successfully fetched prices are cached locally so the page can still show a value if the feed is briefly unreachable). Spot price per troy ounce from gold-api.com; USD→NPR rate from exchangerate-api.com (updated daily). NPR prices are converted to the customary Nepali unit, the tola (11.6638038g), from the USD troy-ounce (31.1034768g) spot price: 1 troy oz = 31.1034768 ÷ 11.6638038 = 2.66667 tola. A local-market premium per metal (shown, and editable, above) is then applied, since raw spot×FX alone undershoots the actual FENEGOSIDA rate — it omits import duty, VAT, and dealer margin. There's no public live feed for that real Nepal rate, so the premium itself is never auto-corrected: it only changes when you update it against an actual quote. What does happen automatically, once a day at 12:00 local time (and once on first load if that's been missed), is a re-anchor of the "Calibrated…" date/spot/amount shown above to that moment's live price under the current premium — so that note and the staleness warning reflect same-day drift, not how long ago someone last typed a number in. Both premiums, and the purity/alert settings, are saved to this browser's local storage. Gold additionally supports a 22K hallmark vs. 24K fine purity toggle (22/24 ratio, ≈91.7%) — Nepal's silver market is not commonly quoted by karat, so no purity toggle is offered for it. A secondary free, keyless price API was evaluated as a fallback data source (goldprice.org, metals.live) but neither responded reliably, so resilience here is retry/backoff plus the local cache above, not a second live source. Indicative only — not an executable trading price.
